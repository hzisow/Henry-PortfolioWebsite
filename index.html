BFF<Project>2026

BFF Classroom

Free financial literacy platform for middle and high schoolers, built for a student-run nonprofit. Teachers run interactive lessons with a class, or students take them alone.

BFF Classroom runs a personal finance curriculum for middle and high schoolers. Students join with a class code and work through 13 lessons. The next lesson stays locked until they score 85%. Mentors get a dashboard showing which questions their class keeps missing. It's React and TypeScript on GitHub Pages with Supabase behind it, and a Gemini edge function handles the tutor chat so the API key never reaches the browser. The curriculum is about 42,000 words in three languages, and I was shipping all of it in one bundle. The lesson path took 10 seconds on a throttled connection. Splitting content per lesson cut that to 4.5.

Stack
  • TypeScript
  • React
  • Supabase
  • Google Gemini API
  • Tailwind CSS
  • GitHub Pages

DECA<Project>2026

MA DECA Chapter Event Board

▲ Used by 13,000+ Massachusetts DECA members

A shared event board for Massachusetts DECA chapters. Anyone can browse and map events; members post their own, and an admin pins the important ones.

MA DECA Chapter Event Board is a shared calendar I built for Massachusetts DECA chapters, with a browsable list and a map view using Leaflet and OpenStreetMap. It runs as a single HTML file with vanilla JavaScript, no framework, backed by Supabase for accounts, storage, and security rules. Members sign in to post and edit their own events. An admin account can pin events and review Instagram feature requests. Photos were the tricky part. A full-size phone photo blew past what localStorage and free Supabase storage could handle, so I added a canvas step that downscales and re-encodes uploads as JPEG before they leave the browser.

Stack
  • JavaScript
  • Supabase
  • Leaflet
  • Vercel
  • OpenStreetMap

SHRT<Project>2026

Faceless Shorts Engine

Turns Reddit stories into narrated vertical Shorts and posts them to YouTube and TikTok without me. Runs on free GitHub Actions minutes.

A GitHub Actions workflow that renders and publishes a full video start to finish. It pulls an unused story from a cache of about 6,500, narrates it with Piper, and builds a 1080x1920 video in FFmpeg over looping gameplay with a title card and color grade. Piper doesn't emit word-level timestamps, so the audio goes back through faster-whisper to recover them for the one-word captions. YouTube and TikTok both publish through one API call. Posting is deliberately irregular so the channel doesn't look scheduled, and the whole thing runs on free CI minutes with no server and no GPU.

Stack
  • Python
  • FFmpeg
  • GitHub Actions
  • Piper TTS
  • faster-whisper
  • CI/CD Automation
